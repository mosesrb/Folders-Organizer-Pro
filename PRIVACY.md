# Privacy Policy

**Effective Date:** August 20, 2026  
**Application:** Folders Organizer Pro  
**Repository:** [https://github.com/mosesrb/Folders-Organizer-Pro](https://github.com/mosesrb/Folders-Organizer-Pro)

Folders Organizer Pro is built with a strict **local-first, privacy-by-design** philosophy. We believe your files and filesystem organization are entirely private to you.

---

## 1. Zero Data Collection & Telemetry
- **No Personal Data:** Folders Organizer Pro does not collect, store, transmit, or sell any personal information (such as your name, email, IP address, device identifier, or location).
- **No Analytics or Trackers:** There are no analytics libraries, tracking pixels, advertising frameworks, or telemetry engines embedded in the software.
- **No Remote Network Requests:** The application runs completely offline and never connects to external servers or cloud services.

---

## 2. Local Filesystem Operations
- **Explicit Access Only:** The application only accesses directories and files that you explicitly open, drag-and-drop, or select via the folder picker.
- **On-Device Processing:** All file scanning, duplicate content hashing (MD5), batch renaming, media conversions, and archive extractions execute strictly on your local computer CPU.
- **No Cloud Synchronization:** Your files, filenames, directory structures, and media never leave your device.

---

## 3. Local Undo History Snapshots
- When an organizing operation is executed, a local snapshot file (`.organizer_history.json`) is created inside the specific workspace folder you chose to organize.
- This snapshot exists solely to enable the **Restore Snapshot / Undo** feature.
- The snapshot file is stored entirely locally on your hard drive and is never uploaded or transmitted.

---

## 4. Open Source Transparency
Folders Organizer Pro is open source software released under the GNU General Public License v3 (GPLv3). You or any independent security researcher can inspect, audit, and verify the entire source code on GitHub.
