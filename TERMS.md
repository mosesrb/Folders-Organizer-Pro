## 2. User Responsibility & File Safety
Folders Organizer Pro provides powerful bulk filesystem automation tools, including batch renaming, file moving, duplicate deletion, directory flattening, and archive extraction.

- **Data Backups:** You are solely responsible for maintaining regular, independent backups of your important files before running batch operations.
- **Folder Selection:** Ensure you verify the selected directory path before executing bulk organizing or cleanup tasks.
- **Dry-Run Recommended:** We strongly recommend utilizing the built-in **Simulation Mode (Dry Run)** to preview planned file moves and renames prior to applying them to your filesystem.

---

## 3. Built-in Safeguards
To assist you in preventing unintended data loss, the application includes several safety mechanisms:
- **System Directory Protection:** Automatically blocks operations on system-critical folders (such as `C:\Windows`, `Program Files`, and bare drive roots).
- **Recycle Bin Deletion:** Deletions (such as duplicate removal and source folder cleanup) use the Windows Recycle Bin (`send2trash`) rather than permanent erasure.
- **Atomic Undo History:** Mutating actions create a local `.organizer_history.json` snapshot allowing one-click rollback of recent file moves.

*Note: While these safeguards are designed to prevent accidental damage, they do not replace standard backup practices.*
